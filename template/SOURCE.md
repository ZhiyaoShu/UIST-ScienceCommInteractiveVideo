## Included files

The root `acmart.cls` was generated without modifications from the packaged `acmart.dtx` by running `latex acmart.ins`. The root `ACM-Reference-Format.bst` is an unmodified copy from the same package.

`acmart/samples/sigconf.tex` was generated without modifications by running the packaged `latex samples.ins`. Its source files and sample bibliography/images are retained. The example PDF and both manuals are the original PDFs supplied by CTAN, not PDFs generated from this project's starter.

`acmart/README`, `acmart/acmart.dtx`, `acmart/acmart.ins`, `acmart/acmart.bib`, `acmart/acm-jdslogo.png`, the manuals, and the retained files in `acmart/samples/` are unchanged upstream files. Unrelated journal examples and alternative conference variants are omitted. The project-specific `main.tex` is a separate starter, with a distinct filename and placeholder content.
